# Description du projet

Projet full stack d'une durée de deux semaines, sur le thème de Dragon Ball.

# Objectif

Afficher une carte (ou plusieurs) en créant une base de donnée dans le back-end et en utilisant celle-ci dans le front-end.

# Outils utilisés

- VSCode
- Git Bash, Git Hub
- Sqlectron
- GoogleSheets
- Trello
- Excalidraw
